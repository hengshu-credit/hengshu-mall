# 商城通用主题：预设配色与页面联动

在后台 `/admin/setting/edit_theme?id=2&type=theme` 的“商城风格”中选择配色。提供 12 套预设，也可以切换自定义，分别设置主题颜色、渐变颜色和辅助颜色（HEX）。右侧同时预览首页、分类页、详情页和个人中心；示例内容用于查看配色，实际页面的内容仍在各自装修页配置。

选择配色后点击“保存配色”或顶部“保存”。只有正在使用的商城主题会影响正式商城，编辑其他主题只改变该主题及其预览。页面切换和 APP 返回前台时刷新配色；页面持续打开时每 30 秒检查一次。网络失败时保留已有颜色，恢复后重试；预览主题与正式主题的请求互不覆盖。

装修组件选择“跟随主题风格”时，价格、渐变按钮、选中态等跟随统一主题色；选择“自定义”时保留组件自己的颜色。商品列表的价格和购物车按钮各自遵循对应的色调开关。图片图标本身的像素颜色不会重新着色，上传素材不做压缩或格式转换。

分类页保留三种组件布局，左侧提供布局缩略图；画布中显示商品图片、名称、价格和按钮样式，可分别配置每种布局的图片适配、圆角、颜色等。商城风格的分类预览也能切换三种布局。画布沿用其他装修页的矩形样式。

## 部署

使用本次生成的 `dist/hengshu-mall-update.tar.gz` 更新后台、PHP 与 H5；Android 覆盖安装 `dist/物色-6.0.8-universal.apk`。无需新增配色数据库表。上传 tar.gz 到 `/root/hengshu-mall/` 后执行：

```sh
cd /root/hengshu-mall
tar --no-same-owner -xzf hengshu-mall-update.tar.gz
cd crmeb-mall
docker-compose -f compose.yml up -d --build
docker-compose -f compose.yml ps
```

更新包继续包含独立京东采集服务。现有配置、数据库、上传目录与京东登录数据按原更新流程保留，详见 [单包更新说明](README-update.md)。本地生成安装包与更新包不等于已经上传服务器或上架应用市场。
