# 页面搜索与底部操作组件

后台入口：`/admin/setting/edit_theme`。商城更新包包含后台、H5、PHP 与独立京东采集服务；Android 安装包单独交付。服务器部署更新包后，在装修中保存所需配置即可。

## 配置方式

- **导航栏**：在各页面的基础组件中按需添加，固定于屏幕底部；内容设置可选“固定一直展示”或“智能隐藏”。智能模式下滑隐藏、上滑显示，回到顶部或切换页面会恢复。未添加导航栏时不占位。商品详情页默认仅保留商品操作栏，仍可自由添加导航组件。
- **顶部搜索栏 / 搜索框**：内容设置可分别添加左、右按钮，每侧最多三个。可设置操作类型、名称、显示文字、原素材图标、颜色、大小、圆角、顺序和显隐。首页、返回、分类、购物车、我的、收藏、分享、客服、扫码和商城内部链接均有对应操作；收藏需要当前商品，详情页分享调用商品分享面板。
- **分类结算栏**：在分类页基础组件中单独添加，三个分类布局都可使用。可设置购物车入口、金额、结算按钮显隐、按钮文字、简洁文字／填充按钮样式、素材图标、颜色、圆角与公共样式。金额和数量来自购物车；空购物车不能结算。分类商品列表、结算栏和导航栏可以自由组合：同时添加时导航在最下方，结算栏在其上方；删除导航后结算栏自动贴底。
- **商品操作栏**：仅商品详情页的基础组件提供添加入口，固定在页面底部；若另行添加导航，则自动位于导航上方。保留“首页／收藏／购物车 + 加入购物车／立即购买”的原布局，可增加客服、分享或自定义入口。复用公共样式，支持图标、按钮颜色、背景、圆角、内外边距、边框、阴影及按钮显隐。收藏、分享、加购与购买继续调用当前商品的原业务逻辑。

旧主题会保留原底栏；新配置删除组件并保存后不会自动恢复。编辑器底部组件固定在画布下方；分类页采用与其他页面一致的矩形画布，没有手机外框。

## 更新服务器

将 `hengshu-mall-update.tar.gz` 上传到 `/root/hengshu-mall/` 后执行：

```sh
cd /root/hengshu-mall
tar --no-same-owner -xzf hengshu-mall-update.tar.gz
cd crmeb-mall
docker-compose -f compose.yml up -d --build
```

更新包保留服务器 `.env`、数据库、上传素材与京东登录数据。此次组件配置使用现有主题 JSON，无需新增数据库字段。Android 用户同时覆盖安装物色 6.0.7，使用原样式的商品操作栏和组件配置。

素材图标直接引用原文件，不压缩、不转格式。后台原素材上传与京东采集部署方式保持在 `README-update.md` 中说明。
