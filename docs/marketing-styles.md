# 营销样式

入口：营销 → 营销样式（`/admin/marketing/style/list`）。

支持创建营销边框与活动氛围。统一配置活动名称、起止时间、图片素材、是否开启、优先级与使用范围；列表提供名称/ID、类型、状态与日期筛选，支持编辑、启停、删除。

- 营销边框：建议使用750×750透明PNG，中央保持透明。以独立图层覆盖商品图片，不修改原图；商品列表、搜索、分类、首页装修商品组件和推荐位共用解析规则。
- 活动氛围：移动端建议750×152，PC建议810×50（选填）。展示在详情主图和商品信息之间；PC未设置时回退移动端图片。PC指uni-app H5宽屏展示。
- 范围：全部商品、指定商品、分类（包括下级分类）、品牌、商品标签。选择器支持搜索、分页与编辑回填，复用现有素材库及范围选择器。
- 同一商品可同时展示一种边框和一种氛围。同类冲突按优先级降序、ID降序选择。分类/品牌/标签随商品当前关联关系匹配。
- 秒杀、拼团、砍价列表与详情以原商品ID复用样式规则，活动价格与交易逻辑不变。
- 新建默认关闭；开启且到达开始时间后在商品接口中生效。已加载页面到期自动移除样式，重新获取商品时重新选取符合条件的样式。停用、删除或编辑后的配置在重新加载商品数据时生效。
- 图片加载失败时隐藏营销图层；氛围图消失时恢复原有商品信息布局。

## 安装与发布

本地已安装。已有站点在更新后执行：

```sh
php think marketing-style:install
```

安装器支持自定义表前缀与重复执行，初始化数据表、后台菜单及权限节点；菜单加载也会补齐模块。全新安装入口已包含 `upgrade/marketing_styles.sql`。发布时同时更新PHP、后台构建产物和uni-app前端。子管理员按现有角色权限分配列表、编辑、启停、删除及相关接口权限。

## 验证

- `tests/regression/run-marketing-styles.ps1`：隔离MySQL，验证安装幂等、输入校验、所有范围、分类后代、优先级、起止时间、启停、软删除、编辑回填及只读权限；不访问业务数据库。
- `tests/regression/marketing_style_browser.cjs`：读取本地商品4作基础测试数据，在独立浏览器中覆盖样式与主题接口；验证商品原图不变、边框尺寸和点击、移动端/PC氛围尺寸、不重叠、到期/图片失败恢复布局。需要本地8011接口、已构建的 `.build/commerce-ui/h5` 和Playwright。
- 实际操作记录见 `docs/reviews/2026-09-11-marketing-styles.md`。
