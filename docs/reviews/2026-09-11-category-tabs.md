# 装修操作栏与分类标签布局修复

- 分类、购物车沿用已有装修页的选中组件行为：操作栏仅在选中组件时显示。取消悬停组件同时弹出另一组操作栏，操作栏高度为 40px，与相邻组件保留至少 4px 间隙；选框向内绘制，避免边线叠加。手机内容布局和已配置间距保持原有含义。
- 分类侧栏增加贯穿整个分类区域的右侧阴影，原生商品分类布局移除侧栏底部多余占位，使阴影覆盖完整高度。
- 二级分类预览改为 75px 等宽单行标签，禁止压缩和换行，支持水平滚动。更多按钮展开三列等宽网格，完整名称可换行；选择后收起并将选中项滚到可见位置。
- 原生布局 2、3复用各自原有横向滚动和分类选择逻辑，统一条目高度、字宽约束、展开面板宽度。展开时保留标签条高度，避免商品区跳动；切换一级分类时收起面板。

## 追加：选框层与菜单底部填充

- 根因一：向内绘制的 outline 被搜索框背景和定位菜单覆盖。改为独立、不可拦截点击的选框层，位于组件内容之上；该层标记为装修控件，不进入封面。
- 根因二：分类外层的内联 `display: flow-root` 覆盖了 flex 布局，内层未获得画布剩余高度。修正外层显示模式与高度传递，菜单背景铺满分类区域，长菜单在自身区域滚动。
- 实际高画布中，最后一个分类底边为 618px，菜单背景与分类组件底边均为 719.8px，末项下方约 102px 的区域已由菜单背景填充。选框层高于侧栏，点击分类仍正常。
- Admin 生产构建与装修页回归通过。搜索框和分类组件分别做了四条边的像素采样，确认选中颜色实际绘制在内容上方；两张局部截图仅供程序采样，没有作为模型输入。日志：`.build/category-selection-admin-build.log`、`.build/category-selection-admin-browser.log`。
