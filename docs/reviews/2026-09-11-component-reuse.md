# 分类与购物车组件复用、商品服务修复

本次继续原装修任务，按用户要求独立完成；UI 在实现后集中核对，不扩展金额计算测试。最终校验包括 HBuilderX 同步到 Android 模拟器的 uni-app 原生页面。

## 修改

- 分类画布将剩余高度分配给分类组件，分类较少时，组件区域延伸到结算栏上方；保留用户配置的组件内外边距。
- 分类搜索框直接复用 `mobilePage/search_box.vue` 和 `mobileConfig/c_search_box.vue`，前端三个分类布局直接使用 `headerSerch.vue`。移除原有独立搜索框预览和设置表单。
- 分类、购物车标题直接使用已有 `page_title_bar.vue`、`c_page_title_bar.vue` 及前端 `pageTitle.vue`，移除重复的标题设置表单，统一按钮、颜色与通用样式。
- 搜索默认配置从原组件移到共享模块，供原组件和分类配置共同读取。旧标题、搜索文案、按钮与隐藏设置迁移到共同配置，保存时保留兼容字段。
- 导航、通用样式和页面工具继续复用现有组件。分类布局、购物车商品与结算业务保留专用组件。
- 商品服务兼容数字和字符串活动类型；无优惠券时活动行可进入活动。统一行间距、标签宽度与活动标签，长文本单行省略且不挤压箭头，去掉末尾多余分隔符，空服务不留空容器。
- 移除商品参数弹窗引用不存在的 `mySpecs` 回调。这个问题在原生运行日志中复现，修复后经 HBuilderX 差量编译同步。

## 实际页面校验

使用未启用的本地装修模板 `id=6`，没有改动活动主题。分类配置已通过真实后管保存为共同搜索、标题结构，原按钮与圆角保留。

- 后管分类组件底边与结算栏顶边一致，额外间隙约为 0px；分类、购物车显示共同的标题设置面板。
- 本地 uni-app H5 的分类搜索框高度为 48px，点击进入搜索页。真实商品详情展示现有优惠券和规格行，打开优惠券、规格选择正常；没有参数或服务数据的商品不会伪造展示数据。
- HBuilderX 5.24 将最新源码同步到 `Wuse_API_30` 模拟器的标准调试基座。ADB 确认前台包为 `io.dcloud.HBuilder`，通过该包的 WebView 读取原生 DOM 与计算布局，没有用浏览器 H5 代替原生结果。
- 原生商品服务显示活动、选择、参数、服务四行；412px 视口下标签宽 43px、上下间距 13px，对应装修端 375px 视口的 40px 和 12px。参数和服务保障抽屉均实际打开，动画结束后底边为 684.19px，与视口底部一致。
- 原生分类使用共同标题和搜索，搜索可进入 `pages/goods/goods_search/index`。分类内容底边 578.185px、结算栏顶边 578.190px；结算栏底边与导航顶边均为 632.190px。切换到商品为空的“电脑办公”分类后，区域仍填满。
- 原生购物车商品区管理切换“取消”，标题同步切换；点击标题取消后恢复管理。标题配置的“分类”页面按钮可返回分类页，返回后分类切换仍正常。

原生使用 `.build/commerce-ui/native-test` 中的源码副本和本地只读测试代理：主题读取真实本地模板，购物车及商品参数/保障使用隔离数据，业务写入不转发。没有修改真实购物车、发布 APK 或覆盖正式 APP。校验未使用截图作为模型输入。

校验结束后，已退出 H5 模板预览，关闭临时浏览器标签、测试代理、原生同步 CLI、调试基座与本次启动的模拟器；用户原有商品详情装修标签保留。
