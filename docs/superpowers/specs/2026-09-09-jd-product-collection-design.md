# 京东商品素材采集

用户要求：使用 CherryPainter/jd-product-crawler，在商城系统外独立运行，接入后台商品采集配置及 /admin/product/add_product。部署在商城同一服务器。

补充要求：京东原生图片/视频及 SVG 等常见格式可上传后台。抓取素材按源文件原始字节存储，不压缩、不转码、不改格式、不加水印或生成缩略图。安全 SVG 保留原字节，不安全 SVG 拒绝。商城本地及云存储驱动统一验证；页面提取直接使用真实 DOM 素材 URL，不使用上游合成尺寸 URL。

## 设计

独立 Python HTTP 服务复用上游 JdProductDetailSpider 的 DOM 提取及详情懒加载方法；商城 PHP 仅通过带 Bearer 密钥的 HTTP 接口访问。服务独立 Compose、浏览器持久化登录目录，不访问商城数据库。上游来源和版本/哈希随服务记录。禁止使用上游 run() 中的随机库存、价格、销量、评论和标签。

服务采用单浏览器、单采集任务。POST /v1/jobs 接收 {url}，立即返回 {job_id,state}；GET /v1/jobs/{id} 返回 queued/running/succeeded/failed，成功携带 product。商品契约：sku_id、source_url、title、price（数值或 null）、images（HTTPS 图片 URL 数组）、video_link（直接视频 URL 或 null）、detail_images、attributes（name/value 数组）、selected_specs（name/value 数组）、warnings（字符串数组）。失败含 error 的 code/message。任务持久化、有时限和保留期；不自动识别验证码，提示人工登录或验证后重试。HLS 清单不合并或转码，提示另行上传原始视频。

商城后台现有商品采集配置增加京东独立采集开关、服务地址、访问密钥。配置由现有设置权限保护；商品采集配置摘要不返回密钥。启用后京东链接自动走该服务，其他平台继续原渠道。复用 POST product/copy，通过 task_id 轮询，并将任务绑定发起管理员。每次 PHP HTTP 请求短超时，避免长连接占用。

商品添加页和列表入口共用现有采集流程；新建页面直接提供“链接采集”按钮。采集完成填入链接对应 SKU 的单规格编辑表单及详情/参数；库存、销量为 0，未知价格提醒补全，默认不上架。保留来源链接，商品保存时沿用素材下载流程。关闭弹窗/离开页面停止轮询，失败保留输入，不自动反复发起采集。

## 验证

Python：URL 与素材域名校验、真实字段规范化、认证、忙碌、超时、任务状态/保留。PHP：字段映射、配置保存、任务隔离、接口响应错误。前端：采集轮询成功/失败/销毁、表单回填；生产构建。容器与本机 HTTP 联调使用明确的合成商品数据；真实京东验收需要商品链接、专用浏览器人工登录。

## 决策

采用独立服务，符合用户部署边界；不把 Python/浏览器依赖加入 PHP 容器。采用异步轮询，适应浏览器详情加载时间。仅导入当前 SKU，因为页面规格选项不能证明其他 SKU 的真实价格及库存。现有工作区有其他改动，本次只修改采集相关文件，不提交其他改动。
