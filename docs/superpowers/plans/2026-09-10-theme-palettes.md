# 商城主题配色与页面联动

**目标：** 通用主题提供可一键选择的预设和自定义配色；装修及商城四个页面使用同一主题色数据，分类布局提供真实图片预览。

**实现：** 扩展现有 theme_data JSON，沿用主题 API、组件跟随主题/自定义开关。统一颜色映射；前端页面显示、返回前台及前台定时检查刷新配色，合并并发请求并阻止旧主题响应覆盖新主题。所有操作在当前会话/master 执行，不使用子智能体，不修改线上数据。

- [x] 共享配色规范：预设、HEX 校验、浅色生成、后台/客户端同源映射，PHP 保存校验；单元回归覆盖无效颜色与旧配置。
- [x] 通用主题：预设色卡/自定义切换、四页面实时预览、保存/还原与未保存提示；装修预览改读当前主题，保留组件自定义色。
- [x] 分类：三种布局图示，真实商品素材预览、图片适配与圆角，布局独立样式保持。
- [x] 前端与交付：已有页面响应主题刷新，失败保留旧配色、预览主题隔离；后台/H5 浏览器回归、Android 编译与更新包验证。
