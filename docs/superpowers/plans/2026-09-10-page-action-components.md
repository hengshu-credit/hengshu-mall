# 页面搜索与底部操作组件实施计划

**目标：** 将固定导航、搜索操作按钮、分类结算栏及商品操作栏纳入同一装修组件体系，后台预览与 H5、App 行为一致。

**实现：** 沿用主题 JSON 和现有业务接口，扩展共享配置规范；导航位于屏幕最底部，业务操作栏在其上方，正文预留实际高度。旧主题读取时兼容迁移，新配置删除组件后不再自动补回。

**技术：** Vue 2、Element UI、uni-app、PHP / ThinkPHP。

**执行约束：** 按用户要求在本会话执行，不使用子智能体；保留当前 master 上其他未提交修改；素材仍使用原文件；不修改线上商品、不下单或支付。

**补充确认：** 所有相关功能均由可增删的组件组合决定。商品详情页默认只有商品操作栏，保持原有电商按钮布局，但不强制禁止主导航。分类页可组合商品列表、结算栏及最下方的导航栏。分类页新增组件须在各布局中显式注册，供 uni-app 原生视图编译器识别。

**原样式补充校验：** 默认白底、首页/收藏/购物车和两个独立胶囊购买按钮，使用原编辑器 36px 按钮高度及 10px 间距；无主题时使用相同三个入口。购买按钮隐藏与自定义背景只作为单独测试用例，不作为默认展示截图。继续保留显隐、图标、颜色、公共样式及独立组件增删配置。
